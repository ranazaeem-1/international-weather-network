# IWN project instructions

## Two channels in this repo

**First question for every new video:** "Which channel is this for: IWN or Carver Weather Desk?"
Ask it before any research, download or script work. Skip it only if the user has already named the channel.

- **IWN** → follow `worflow.md`, plus the IWN rules below.
- **Carver Weather Desk** (@CarverWeatherDesk) → follow `carver-weather-desk/workflow.md`. Setup is in `carver-weather-desk/README.md`.
  - Host: Glenn Carver, a HeyGen avatar.
  - The user gives a topic, sometimes with clips. We return **ONE HeyGen script**, for a video of **12:00 at most**.
  - The user sends back the HeyGen render. We deliver the MP4 and a CapCut draft.
  - Never mix the two channels' branding.

Thumbnails are no longer part of the IWN workflow (user, 21 Oct 2026): do not make thumbnails, and do not ask which thumbnail design to use. Follow `worflow.md` for production and for the upload-copy (metadata) format.
